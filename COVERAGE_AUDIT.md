# Study practice coverage map

Version 2.5.0 · 18 October 2026

Content availability audit; not a mastery score or guarantee of exhaustive scientific knowledge.

The current app contains 220 example activities representing 200 distinct worked scenarios and 660 dropdown-question slots. Shared concepts intentionally reuse activities across app surfaces. The 45 new cases add source interpretation, method connections and defence practice across all 15 topics.

## Coverage standard

Each topic has worked understanding, application, evidence interpretation, mistake recognition, method connection and defence practice. Three optional dropdown questions are available per activity; one response permits continuing. No writing, rubric or self-assessment gate is required. Definitions remain optional.

## Unresolved source information

- Exact platform-specific commands and full intermediate analysis records are not supplied.
- The heat-map transformation and imputation implementation need the original matrix/code.
- Exact plot percentages cannot be recovered by guessing image heights.
- Independent patient prevalence, somatic status, causal effects and clinical performance are not established by these descriptive summaries.

These limitations are taught honestly; missing evidence is not filled with invented results. New practical examples can expand application coverage, but cannot certify complete understanding.
